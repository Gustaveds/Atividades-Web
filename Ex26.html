Image Sources

Para encontrar as URLs das imagens, utilizei o navegador Chrome. Cliquei com o botão direito do mouse sobre a imagem desejada e selecionei a opção "Copiar Endereço da Imagem"

No elemento <img>, utilizei os seguintes atributos:

  • src: Este atributo (fonte ou source) é essencial e especifica o caminho URL da imagem.
  • alt: Este atributo fornece um texto alternativo (se porta como uma legenda) para a imagem. É importante para acessibilidade, pois leitores de tela o utilizam para descrever a imagem para usuários com deficiência visual. Também é exibido se a imagem não puder ser carregada.
